# Phase 2 — Design Moodboard

## Visual Philosophy
The design should feel like a calm digital gallery — a daily vibe check of the planet with no clutter, no scroll, no noise.

### Colors
- Background: #FAFAFA (Off-white, paper tone)
- Text: #111111 (Near-black neutral)
- Accent: Pulled dynamically from emojis; they are the color.
- Hover / Focus: Subtle scale-up, no shadows.
- Optional Dark Mode: Background #0D0D0D with same emoji hues.

### Typography
- Primary Font: Inter (Google Fonts)
- Backup: system-ui, sans-serif
- Title: Uppercase, 600 weight, tracking-wide.
- Footer: Regular, 0.9rem, gray (#888).

### Spacing
| Element | Padding | Margin | Notes |
|----------|----------|--------|-------|
| Page Container | 24px top/bottom | auto sides | Centered layout |
| Emoji Row | 40px top / 40px bottom | 0 | Equal breathing space |
| Footer | 24px top | 16px bottom | Matches visual rhythm |

### Motion
- Emoji hover → scale(1.1), 120ms ease-in.
- Reaction click → scale(1.2) bounce, 100ms.
- Page load → fade-in 300ms.

### Tone
Whitespace is the hero. Emojis are the narrative. The UI should feel like a calm wall of emotional symbols — the world's vibe in a glance.
